# PROJECT OVERVIEW
This project focuses on designing and developing a structured relational database system for hospital management, addressing the limitations of an existing Excel-based record-keeping system. The project involves migrating hospital data into a centralized database while organizing essential information related to patients, doctors, departments, appointments, prescriptions, laboratory reports, and billing. The primary objective is to improve data integrity, consistency, accessibility, and overall database management.
The database design addresses key challenges such as unique identification, maintaining relationships between records, enforcing data validation rules, preventing invalid appointment scheduling and double-booking, and implementing role-based access to sensitive patient information. It also aims to simplify hospital reporting by enabling monthly revenue summaries across departments. The project demonstrates how a well-structured relational database can improve data management, enforce business rules, and support efficient hospital operations.
